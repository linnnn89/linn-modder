# 二进制、资源与容器抽屉

先识别 magic、版本和实际消费方；同为 `.dat` 可以分别是 UnityFS、序列化模型或私有数据。只在有写入证据时改副本，未识别的格式交给[逆向技能](../../reverse-engineering/GUIDE.md)。

| 文件类型 | 保留的合同 | 有意义的验证 |
|---|---|---|
| PNG/DDS/纹理 | 尺寸、alpha、颜色空间、通道、压缩、mip、图集 rect/padding/pivot | 头信息+解码+目标尺寸下观察；DDS 编码与通道见[目标格式](../../asset-pipeline/references/target-format.md) |
| PSD/分层美术 | 图层语义、遮罩、混合、画布、隐藏部分 | 在真实兼容编辑器重开并切换图层；不是只看合成图 |
| 音频 | 编码器、采样率、声道、时长、loop 元数据、音量 | 解码并听首尾/循环接缝；不要把扩展名改成游戏要求的编码 |
| 3D/Live2D | 骨架/参数/材质/纹理依赖、单位、坐标、蒙皮、绑定与版本 | 目标运行时动作/表情检查；导出 FBX/VRM/PNG 本身不证明能替换游戏模型 |
| pak/bundle/uasset/XNB/私有容器 | 版本、依赖、路径大小写、顺序、对齐、offset/size、压缩、校验 | [无改动回封 → 单项改动 → 独立重读](../../reverse-engineering/references/archive-roundtrip.md) |
| 二进制存档 | build、schema、校验、外部文件依赖和云同步状态 | 只改副本；确认可恢复，且用该游戏加载验证后才能称为可用 |

解包前限制总大小/条目数并防路径越界、链接、重复名；不要一次解整个多 GB 成品包只为找几个文件。工具能提取并不等于能回封。确定性无损格式应字节一致；允许重压缩/时间戳差异时，比较解码后的条目和未改元数据，不能以“图片看着差不多”证明归档完整。

先写新的 staged 文件、关闭写入并校验，再准备部署；不要原地改唯一副本。DLL/EXE、签名或保护边界不属于普通素材编辑：优先官方扩展点，不提供保护绕过路线。

工具作者与规范入口见[引擎与文件资料](../../mod-research/references/engine-and-file-sources.md)。
