# 字体与本地化抽屉

先确认实际语言键、字符串表、字体渲染器、目标编码和游戏版本。语言文件可能同扩展名但不是标准 YAML/CSV；使用[文本数据规则](../../file-mod/references/text-and-data.md)。

| 需要保留 | 检查方法 |
|---|---|
| 字符串键与 ID | 用稳定键修改，避免按行号、界面顺序或中文名字匹配 |
| `{0}`、`%s`、命名插值、转义与富文本 | 比较源/译文的参数集合与类型；标签成对；不要翻译脚本表达式 |
| 单复数、性别、上下文 | 按引擎翻译 API 处理，避免简单全局替换相同英文 |
| 汉字/假名/全角标点/异体字 | 目标字体实际渲染样本；缺字应检查 fallback 和图集，而不只查字体文件存在 |
| 字重、baseline、line height、SDF 参数 | 对齐按钮、数值和对话文本；动态字体图集与静态位图字体分开验证 |
| 中日文断行和长文本 | 检查标点、名字、选项、tooltip、最大文本长度与裁剪；别一律缩小字号 |

字体文件仅从许可明确的来源取得；核对是否允许打包/子集化，保留许可证。免费阅读字体文档不等于字体可再分发。声音同样区分参考、使用和重新发布许可。

验证用户要求的语言切换、重启后保持、fallback、输入法（若修改可输入控件）、搜索/排序和实际控件宽度。只做本地化时不擅自改剧情、角色设定或所有语言字段。

[Godot/Ren'Py 本地化与其他三语入口](../../mod-research/references/art-and-ui-sources.md)提供实现参考，实际游戏字符串合同优先。
