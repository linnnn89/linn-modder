# Showcase video

## Minimum workflow
1. Confirm the requested duration/style and whether usable clips already exist.
2. Record only if needed and authorized; make the scene reproducible and restore affected test saves.
3. Inspect contact sheets, choose in/out times, then write the EDL.
4. Render a preview, check framing/audio/credits, then render the final video.
5. Deliver the file; publish only when authorized.

A showcase is a separate requested deliverable, not a requirement for every mod/code task.
Preserve creator attribution and do not imply third-party footage was made with this toolkit.

| Task | Read |
